# 部活対抗ファイト

ホーム画面名は「部活ファイト」、App Store用の名前は「部活対抗ファイト」。19部活で対戦する、横画面の2D格闘ゲーム。タイトルの「バトル」からCPU対戦、「練習」から体育教師を相手にした練習へ進めます。通常対戦は60秒、2本先取。「2人対戦」は準備中の表示のみで、開始できません。

## 起動と操作

Unity **6000.5.3f1** を使用。このリポジトリを取得してUnity Hubに追加し、`Assets/Scenes/Playground.unity` を開いて **Play**。必要なパッケージはUnityでプロジェクトを開くと復元されます。

選択画面の下の一覧から、帰宅部を先頭に19部活を選べます。大きいプレビューは待機アニメーションで表示されます。まず自分の部活を選ぶと相手側へ進みます。選択中のカードは緑色の枠と画面上の見出しで示します。自分・相手のカード全体を押すと選択する側を切り替えられます。相手の上にある「CPU おまかせ」は0.12秒ごとに相手候補を切り替え、抽選が終わるとその相手で止まります。「バトル」を押したときだけ対戦を始めます。舞台はグラウンド・教室・体育館の3つ。得意舞台のカードには「ステージ効果 ×1.3」を表示し、攻・速・守が赤くなります。

CPUの強さは1〜5。戦い方は試合開始時にCPUが決め、Lv4・5は部活の近接・遠距離の特性に合わせて間合いを選びます。CPUの基礎能力値は難易度で増えません。

画面左のスティックで左右に移動します。右はゲームコントローラーと同じ菱形配置で、上が「跳ぶ」、左が「守る」、下が「小攻撃」、右が「強攻撃」です。移動とジャンプ・防御・攻撃は同時に入力できます。画面の操作説明はタッチ操作だけを表示します。

中央の選択はステージ、レベル1〜5、バトルの3段です。選択中のステージはオレンジ。抽選ボタンはCPUの上にあります。タイトルのメインボタンはバトル・練習・2人対戦で、設定・操作は幅が約半分のサブボタンです。

背景は画面いっぱいに描画し、ボタンはiOSの安全領域に収めます。部活名・HP・防御ゲージ・獲得本数は上部の同じ枠に表示し、時計の下にステージ名は出しません。KO時は0.75秒間、ゲームと描画の進行を20%にし、各本でKOを表示します。2本先取後は自分視点のWIN／LOSEと、同じ56pxのスコアを表示します。

小攻撃は3段コンボにでき、空中攻撃も使えます。防御は正面に有効で、ゲージを使い切ると崩れます。強攻撃の動作が終われば、待ち時間中でも移動・ジャンプ・防御・小攻撃ができます。

## 音・設定

「設定」と「操作」はタイトル画面に集約しています。設定ではBGMと効果音を別々にオン／オフでき、次回起動にも保存します。対戦・選択画面には音設定を表示しません。

BGMは3・2・1の間は流れず、FIGHTとともに始まり、実際に戦っている60秒間だけ繰り返します。一時停止では曲位置を保ち、再開時に続きから流れます。ラウンド終了・試合終了・タイトルへ戻ると止まり、次のFIGHTで冒頭から開始します。練習ではBGMは流れません。

曲は **8-Bit Battle Loop / Theodore Kerr (Wolfgang_)**。公開元は https://opengameart.org/content/8-bit-battle-loop 、ライセンスはCC0 1.0 Universalです。著作権表記と音源の取得・ループ処理記録をプロジェクトに同梱しています。戦闘中の時計・カウントダウン・FIGHTはドット描画、メニューは通常フォントを使います。

## 練習

タイトルの「練習」を押すと、カウントダウンなしで開始します。相手はジャージ姿の体育教師で、移動・攻撃・防御をせず、その場に立ちます。何度攻撃しても終了せず、HP・スタミナ・残り時間・ラウンドのHUDは表示しません。

左上の丸いキャラクターアイコンを押すと、帰宅部を先頭に19部活の丸いアイコン一覧が開きます。一覧を開いている間だけ練習が停止し、部活を選ぶとその場で切り替わって再開します。「×」で変更せず閉じられます。選んだ部活は次回起動にも保存されます。一時停止の「リセット」で練習をやり直せます。

帰宅部の強攻撃は自転車で前方へ最大640px突進し、命中または走行終了で降ります。帰宅部には地元補正がありません。

サッカーは低い位置から上がるボール、野球とハンドボールは頭付近から腰へ落ちる投球。バレーとテニスは頭上から下がる強いサーブです。遠距離攻撃にも射程があり、端から反対の端へは届きません。地元では弾の飛ぶ速さが1.3倍になりますが、弧の形と射程は維持します。

科学は歩行132px/秒、薬瓶280px/秒と遅く、瓶は腰から胸へ当たる放物線を描きます。直撃は8ダメージ、毒は毎秒2ダメージを7回。ガードは直撃を0にしても毒を受けます。再度当たると残り期間を7秒へ戻し、重複しません。教室では毒が毎秒2.6ダメージになり、期間は7秒のまま。ジャンプや移動で瓶を避けられます。

## 開発

戦闘チェックはUnityメニューの `Club Clash > Run combat checks` から実行できます。広告・レビュー・画面操作の回帰テストは `Assets/Tests` にあります。レベル・経験値・成長・装備購入は未実装です。

画像はimagegenで生成しています。Notoフォントのライセンスは `Assets/Resources/Fonts/LICENSE.txt`、BGMのライセンスと取得・処理記録は `Assets/ArtSources/Audio` にあります。BGMの原音源は `Club Clash > Prepare loop music` で再処理できるよう同梱しています。

## リポジトリ構成

- `Assets`：ゲームのコード、シーン、画像、音声、アイコン、開発用ツールとテスト。Unityの参照を保持するため `.meta` ファイルも管理します。
- `Packages`：パッケージ定義とバージョンの固定情報。
- `ProjectSettings`：Unityのプロジェクト設定。

Unityのキャッシュ、ビルド、ログ、個人設定、IDEの生成ファイル、ストア素材、検証結果は `.gitignore` で除外しています。開発用ツールが生成する `Builds`、`Verification`、`AppStore` もコミット対象外です。
